# Soul & Energy Healing Tools

Professional web tools for soul contract readers and reiki practitioners.

## Features

### 1. Soul Contract Calculator
- Calculate soul contract numbers from names using sacred numerology
- Based on Hebrew alphabet correspondence and numerology
- Provides interpretations for Soul Destiny, Spiritual Goal, Physical Goal, and Talents
- Export readings as downloadable reports
- Save readings for client records

### 2. Reiki Session Timer
- Professional timer with preset session types (Full Body, Chakra, Quick)
- Visual chakra tracking with color-coded progress
- Hand position guidance
- Session logging and client tracking
- Audio/visual notifications for position transitions

### 3. Client Session Tracker
- Manage client information and contact details
- Track session history with dates, types, and notes
- Revenue tracking per client
- Export client data for records
- Search and filter capabilities
- Privacy-first: all data stored locally in browser

### 4. Energy Center Guide
- Comprehensive reference for all seven chakras
- Detailed information on location, purpose, and healing techniques
- Reiki symbols reference
- Quick healing technique guide

  - Custom domain support
  - HTTPS included
  - Continuous deployment from Git

  - Perfect for static sites
  - Custom domain support
  - Easy updates via Git

  - Email hosting included

### Option 3: Full SaaS Platform
- **Firebase**: Pay-as-you-go
  - User authentication
  - Cloud database (sync across devices)
  - Hosting included

  - Full control
  - Advanced features
  - Global CDN

## Quick Start - Local Development

1. Clone or download this repository
2. Open `index.html` in a web browser
3. All tools work offline - no server required!

## Quick Start - Deploy to Netlify (Free)

1. Create account at [netlify.com](https://netlify.com)
2. Click "Add new site" → "Deploy manually"
3. Drag and drop the entire project folder
4. Your site is live!
