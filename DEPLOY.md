# GitHub Pages Setup Instructions

Your web tools are ready to be deployed! Follow these steps to enable GitHub Pages:

## Option 1: Enable GitHub Pages (Recommended)

1. Go to your repository: https://github.com/abalmos/playground

2. Click on **Settings** (top right)

3. Scroll down to **Pages** (in the left sidebar)

4. Under **Source**, select:
   - Branch: `claude/gh-pages-01VAUctToEdqL1AiGssDiNjL`
   - Folder: `/ (root)`

5. Click **Save**

6. Wait 1-2 minutes for deployment

7. Your site will be live at: `https://abalmos.github.io/playground/`

## Option 2: Merge to Main Branch (Alternative)

If you want to use the main branch for GitHub Pages:

1. Go to: https://github.com/abalmos/playground/pull/new/claude/gh-pages-01VAUctToEdqL1AiGssDiNjL

2. Create a Pull Request

3. Merge the PR to main

4. Go to **Settings** → **Pages**

5. Select Branch: `main`, Folder: `/ (root)`

6. Click **Save**

## Custom Domain (Optional)

To use your own domain (e.g., soulhealingtools.com):

1. Buy a domain from Namecheap, GoDaddy, etc.

2. Add a CNAME file to your repository with your domain name

3. In your domain registrar's DNS settings, add:
   - Type: CNAME
   - Name: www
   - Value: abalmos.github.io

4. In GitHub Pages settings, add your custom domain

5. Enable "Enforce HTTPS"
